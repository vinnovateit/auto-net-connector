Latch package repositories

APT and DNF repositories for Latch CLI.

Debian and Ubuntu

curl -fsSL https://vinnovateit.github.io/latch/latch.gpg | sudo tee /usr/share/keyrings/latch.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/latch.gpg] https://vinnovateit.github.io/latch/apt stable main" | sudo tee /etc/apt/sources.list.d/latch.list
sudo apt update
sudo apt install latch-cli

Fedora and RPM-based

sudo dnf config-manager --add-repo https://vinnovateit.github.io/latch/latch.repo
sudo dnf install latch-cli
